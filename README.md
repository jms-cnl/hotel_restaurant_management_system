# Hotel and Restaurant Reservation with Tracking System

A web-based system for managing hotel and restaurant reservations, tracking reservation status, and providing role-based access.

## Features

- User Authentication
- Role-Based Access Control
- Hotel Management
- Restaurant Management
- Room Management
- Table Management
- Reservation Management
- Combined Hotel + Restaurant Reservations
- Reservation Tracking
- Dashboard
- Search and Filtering
- Reports
- Notifications

## Technology Stack

- React
- TypeScript
- Node.js
- Express.js
- Supabase
- GitHub
